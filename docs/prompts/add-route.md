# Prompt: Add A Route

```text
Add a route to this kiss-server application.

Instructions:
- Inspect the current application structure and route style first.
- Choose fastGet only if the new route is an exact fixed GET response.
- Choose a normal route for dynamic logic, path params, query-dependent behavior, request body handling, validation, database calls, file calls, or network calls.
- Keep Java 17 compatibility.
- Do not add frameworks or JSON dependencies unless the route explicitly requires one.
- Keep the handler small and avoid unnecessary allocation.
- Add or update focused tests.
- Update curl examples or docs if the route is user-facing.
- If performance is discussed, label fast-static and normal-route behavior separately.
```
